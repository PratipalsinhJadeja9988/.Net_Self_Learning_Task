CourseDesk - Student Course Registration (ASP.NET Core MVC, .NET 8)

Run in Visual Studio 2022: open CourseDesk.sln and press F5.
Run from command line:     dotnet run   (then open the URL shown)

Pages: /  |  /Student/Create  |  /Student  |  /Student/Details/1

Features
- Server-side validation with Data Annotations and ModelState.IsValid
- Live browser validation (JavaScript reads the same rules from the model)
- Search, semester filter and column sorting on the student list
- Light and dark theme, success message, print and copy-email on details page
- Data is stored in a static list and is lost when the app stops
